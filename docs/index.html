Reproduce the machine

The repository contains the complete working configuration (LinuxCNC 2.9.10, Mesa 7I96S with PktUART firmware, Modbus VFD, probe, tool setter, pendant), wiring tables and an AGENTS.md written so an AI assistant can walk you through rebuilding it on your own hardware.
