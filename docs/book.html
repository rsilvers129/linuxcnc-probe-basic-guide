Probe Basic, Explained

An illustrated guide to running a CNC router or mill with LinuxCNC and the Probe Basic screen, from homing to the last tool change.

Why this guide exists

Probe Basic is one of the best-looking and most capable screens for LinuxCNC. It has a full probing suite, a tool-setter routine, conversational programming and a database tool table. Its official documentation covers installation and configuration well, but the parts a new operator needs most are thin. The interface pages are mostly screenshots with headings, and nothing walks you through a real job from start to finish.

This guide fills that gap. It was written while setting up and running a real machine: a Chinese 6040 router converted from Mach3 to LinuxCNC with a Mesa 7I96S card. Every procedure here was done on that machine, and every mistake in the troubleshooting chapter actually happened.

Who it is for

  • New Probe Basic users who can start LinuxCNC but are not sure what half the buttons do.
  • People coming from Mach3, UCCNC or GRBL senders, where work offsets and tool lengths work a little differently.
  • Anyone (or any AI assistant) who wants to reproduce this exact machine. The repository holds the complete, working configuration: Mesa firmware, HAL, INI, Modbus spindle control, wiring tables and calibration values. See AGENTS.md in the repository root.

1. The two ideas everything rests on

Almost every confusing moment in Probe Basic comes back to two questions:

  1. Where is the part? That is answered by the work offset.
  2. Where is the tip of the cutter? That is answered by the tool length offset.

Once both are right, a program that says "go to X0 Y0 Z−0.3" puts the tip of whatever cutter is loaded exactly 0.3 mm below the top of your part, at the point the program calls zero.

Machine coordinates

When you press REF ALL (home), each axis drives to its switch and LinuxCNC sets machine coordinates. They are fixed to the frame of the machine and never change until the next homing. On most routers machine Z0 is the top of Z travel, so every Z position below it is negative.

Machine coordinates are what the soft limits use. They are also what tool-change positions, the tool setter position and other "fixed places on the table" are stored in.

Work coordinates and the work offset (G54)

Your CAM program is not written in machine coordinates. It is written relative to the part: typically X0 Y0 at a corner or the center, and Z0 on the top surface. The work offset connects the two. It is simply the position of the part's zero point, expressed in machine coordinates.

LinuxCNC has nine work offsets: G54, G55, G56, G57, G58, G59, G59.1, G59.2 and G59.3. Each is a separate stored zero, so you can keep several fixtures or vises set up at once and pick one per job. Most people only ever use G54, which is also the default selected at startup.

You can set a work offset three ways:

  • With the probe (the best way). A probing routine finds the part's edges or center and writes the result into the active offset. See chapter 5.
  • By touching off: jog to a known point and press ZERO X / ZERO Y / ZERO Z (or use the touch plate for Z).
  • By typing: G10 L2 P1 X… Y… Z… writes G54 directly in machine coordinates. G10 L20 P1 X0 means "make where I am now X0 in G54".

Work offsets are saved in the parameter file (the .var file), so they survive a restart. After a restart you only need to home again.

On the 6040. The isogrid test job used G54 = X 191.174, Y 271.276, Z −102.427. That is the center and top of a piece of plywood, found with the 3D probe's RECT BOSS routine.

Tool length offsets (G43)

LinuxCNC needs to know how far each cutter's tip sits below a fixed reference point on the spindle. On most hobby machines that reference is the face of the collet nut (sometimes called the spindle nose). The distance from that face down to the tip is the tool's length, stored in the tool table.

G43 Hn tells LinuxCNC "the tool in the spindle is tool n; apply its length". From then on, Z positions and the Z readout refer to the tip of that tool. G49 cancels it, and Z refers to the nut face again.

This is why a program can change from a 6 mm end mill to a 1/8" end mill and keep cutting at the right depth. Each tool's length is different, but G43 corrects for it.

Tool lengths are measured with a tool setter, a switch fixed to the table that the cutter is lowered onto. See chapter 6.

Why both matter: the shared reference

The tool setter, the touch plate and the 3D probe all agree because they all use the same reference: the nut face.

  • The setter measures each tool's length from the nut face.
  • The probe is just another "tool" in the table (often T99), with its own measured length.
  • When the probe touches the top of the part, LinuxCNC knows where the ball tip is (because G43 is active for T99). It stores the part's top as G54 Z0.
  • When the program later loads T1 and applies G43 H1, "Z0" puts T1's tip on that same surface.

The most common mistake. Probing with the probe in the spindle but without G43 active for it. LinuxCNC then thinks the nut face touched the part, and Z0 ends up one probe-length too high. On the 6040 that was 46.87 mm, so the program cut air. The fix is to always load the probe with M6 G43 (chapter 5).

2. A tour of the screen

Probe Basic's window has two parts:

  • The top area changes with the tab you pick: MAIN, FILE, TOOL, OFFSETS, PROBING, CONVERSATIONAL, SETTINGS and STATUS. ATC and USER tabs appear when they are enabled.
  • The control strip along the bottom never changes. It holds everything you need while a program runs.

The bottom control strip

Learn this strip first; it is where you spend most of your time.

Program control (left)

STOP Aborts the program. You lose your place; restarting mid-program needs RUN FROM LINE.
FEED HOLD Freezes motion immediately and keeps your place. The spindle keeps running. Press CYCLE START to continue.
SINGLE BLOCK When lit, each CYCLE START runs one line. Good for stepping through the start of a new program.

Spindle and jog

  • FWD / STOP / REV run the spindle manually at the default speed.
  • The JOG panel has continuous and step jogging (1, 0.1, 0.01 mm on the reference machine).
  • The JOG / WCS / PLOT / USER sub-tabs switch the small panel between jog buttons, work-offset buttons, preview options and user buttons.
  • MAN / AUTO / MDI select the machine mode. Probe Basic usually switches for you.

The tabs

MAIN

The 3D toolpath preview (backplot) and the G-code listing. Preview buttons: ISO / X / Y / Z views, PAN, ZOOM ±, PGM EXT (fit the program), MCH EXT (fit the machine), PATH and CLEAR (the live tool trail), ORTHO/PSPECT.

The MDI sub-page has a keypad, MDI history and RUN FROM LINE controls. RUN FROM LINE does not restore the state before that line: position, feeds, work offset, tool, tool length, spindle. Only use it at the start of an operation, where the program sets all of those itself.

FILE

The file browser for your nc_files folder and USB sticks. LOAD G-CODE opens a program. TO PC / TO USB copy files. There is also a built-in G-code editor (EDIT G-CODE, FIND/REPLACE, SAVE AS).

TOOL

The tool table, plus two panels:

  • Tool change panel: M6 G43 for a tool number. LOAD SPINDLE / UNLOAD SPINDLE are for ATC machines.
  • Electronic tool setter: TOUCH OFF CURRENT TOOL measures the loaded tool on the setter. See chapter 6.

Table columns: tool number, pocket, Z (length), diameter, remark, and an ATC checkbox. ATC only matters with an automatic tool changer: it marks tools that fit in the carousel, and does nothing on a manual-change machine. SAVE TABLE commits your edits.

OFFSETS

All nine work offsets as a table, plus the current one broken down. See chapter 4.

PROBING

Two sub-tabs:

  • TOUCH PROBE: the probing parameters, the PROBE RESULTS panel, and the routine pages: OUTSIDE CORNERS, INSIDE CORNERS, BOSS AND POCKET, RIDGE AND VALLEY, EDGE ANGLE, ROTARY AXIS, CALIBRATE and PROBE HELP. See chapter 5.
  • TOOL SETTER: the setter parameters (spindle zero, feeds, travel, retract) and SET TOOL TOUCH OFF POS. See chapter 6.

CONVERSATIONAL

Generates simple programs without CAM: FACING, HOLE OPS (with XY COORD, PATTERN and THREAD MILL), PERIMETER, POCKETS and MISC. See chapter 9.

SETTINGS and STATUS

SETTINGS holds startup options (which tab opens first), programmable-coolant constants, the spindle-rpm display source and the angular jog link. STATUS shows machine status messages and the error history: look here when something "did nothing".

3. Your first job, start to finish

This is the complete sequence for a CAM program with several tools, a part held on the table, a 3D probe and a tool setter. It is the routine used for every job on the reference machine.

1. Power up and home

  1. Switch on the control box (stepper drivers, VFD, Mesa card), then start LinuxCNC.
  2. Release the E-stop and press POWER.
  3. Press REF ALL. Each axis homes in turn; Z goes first on most routers so the spindle lifts clear. The button then reads HOMED.

You must home after every LinuxCNC start. Work offsets and tool lengths are kept, but LinuxCNC can't know where the axes are until they find their switches.

2. Load the program

FILE tab → select the file → LOAD G-CODE. Then check the preview on the MAIN tab:

  • The whole toolpath should draw. If you only see a few lines, the preview stopped at an error; check STATUS. (A subroutine that probes during the program can cause this. See chapter 11.)
  • PGM EXT zooms to the program. Check it is roughly where you expect relative to the part.

3. Load the probe

Put the 3D probe in the spindle. In the T box at the bottom type the probe's tool number (often 99), then press M6 G43.

  • M6 tells LinuxCNC that tool is now in the spindle. On a manual-change machine it lifts Z and asks you to insert it; just confirm.
  • G43 applies the probe's measured length, so Z now refers to the ball tip.

Check: the T box shows 99, the G43 button is lit, and LENGTH shows the probe's length. Tap the stylus; the probe LED on screen should light. A normally-open probe that is unplugged never triggers, so always test it.

4. Find the part with the probe

Go to PROBING → TOUCH PROBE.

  1. Turn PROBE POSITION ONLY off. While it is on, routines only measure and report. While it is off, they write the result into the active work offset, which is what you want now.
  2. Pick the routine that matches the part. For a rectangular block or board whose center is your zero: BOSS AND POCKET → RECT BOSS (bottom row, middle).
  3. Enter the part's approximate size in X HINT and Y HINT. The routine steps out by half the hint plus the step-off width before it drops down beside the part.
  4. Jog the probe over the middle of the part, within a few millimetres of center, with the ball 3–8 mm above the top. That must be within MAX Z DISTANCE.
  5. Press the routine button. The probe touches the top (Z0), then both X sides and both Y sides, and returns over the center.
  6. Read PROBE RESULTS: X WIDTH and Y WIDTH should match the part. The DRO should now read about X0 Y0, and Z = the Z CLEARANCE.
  7. Turn PROBE POSITION ONLY back on, so a later measurement can't move your zero by accident.

For a corner zero instead, use OUTSIDE CORNERS and pick the corner. Chapter 5 covers every routine.

5. Check Z before cutting (30 seconds, worth it)

With the probe still loaded and G43 on, the DRO Z shows the ball's height above the part. Hold a ruler to the gap. If the DRO says 55 and the gap is 55 mm, the zero is right. If the gap is about one probe-length different, G43 wasn't active during probing: redo step 3, then step 4.

6. Run

  1. Take the probe out.
  2. Turn the F (feed override) slider down to 25–50 % for the start.
  3. Press CYCLE START.
  4. At the first T1 M6 the machine lifts Z and asks for tool 1. Insert it and confirm. - With the M6 remap (chapter 6): it drives to the tool setter, measures the tool and continues. Nothing else to do. - Without the remap: the program uses whatever length is in the tool table, so you must have measured the tool beforehand with TOUCH OFF CURRENT TOOL.
  5. Watch the first plunge. The tip should land where the program says, for example just below the top surface for a facing pass. If anything looks wrong, press FEED HOLD.
  6. Once it looks right, bring the feed override back to 100 %.

7. Tool changes and pauses

  • Every M6: lift, prompt, insert, confirm, measure (with the remap), continue.
  • M1 (optional stop): the program pauses only if M01 BREAK is lit. Press CYCLE START to continue.
  • Pausing: FEED HOLD, then CYCLE START to resume. The spindle keeps turning during a hold, so keep hands and the vacuum nozzle away from the cutter. In metal, keep holds short: a spinning tool that is not moving rubs and heats up.

8. When it finishes

The program ends with M30: spindle off, offsets kept. The work offset stays valid as long as the part doesn't move, so you can re-run, or run a second program on the same part, without probing again.

On the 6040. The first job on this machine was an aluminum isogrid plate, test-cut first in plywood. It used three tools: a 6 mm single-flute for facing and roughing, a 1/8" single-flute O-flute for corners, walls, holes and the profile, and a 90° chamfer mill. G54 came from RECT BOSS on the stock, and every tool was measured on the setter at its M6.

4. The OFFSETS tab

Chapter 1 explains what a work offset is. This chapter is the screen.

The table (left)

One row per work coordinate system, in order: G54, G55, G56, G57, G58, G59, G59.1, G59.2, G59.3. Columns: X, Y, Z, A (the zero point, in machine coordinates) and R (rotation in degrees, set by EDGE ANGLE → SET ROTATION WCO).

  • SAVE TABLE / RELOAD TABLE write or re-read the parameter file. Values set by probing or ZERO buttons are already saved; use these after editing cells by hand.
  • CLEAR SELECTED / CLEAR ALL zero offsets. CLEAR ALL wipes every fixture you have set up.

Selecting the active offset (right, top)

The buttons G54 … G59.3 select which one is active. The lit one is what programs, probing and the ZERO buttons use. A program can also select one itself with a line like G55, and most CAM posts write G54 at the start.

The breakdown table (right, bottom)

For each axis:

Column Meaning
SET TO ZERO The ZERO button: makes the current position zero in the active offset.
WC CURRENT POSITION Where the tool tip is relative to the part.
MACHINE COORDS Absolute position.
WC OFFSET The active offset's value, the same as the table row.
G52/G92 OFFSET A temporary extra shift. Keep it 0 unless you use G52/G92 on purpose.
TOOL OFFSET The active tool length (Z) from G43.

They always add up: WC current = machine − WC offset − G52/G92 − tool offset.

Worked example from the reference machine, with the probe (length 46.8736) loaded and G43 on, and Z all the way up:

Z:  0.000 − (−102.4266) − 0 − 46.8736 = 55.553

So the probe's ball was 55.55 mm above the part's top surface. A ruler confirmed it.

Good practice

  • Don't press ZERO buttons you don't mean to. Each one silently moves your part's zero.
  • Use one offset per fixture. G54 for the vise, G55 for a second vise, G56 for a jig. Then a program for a different fixture just selects its offset, and nothing needs re-probing.
  • Write offsets down for repeat fixtures. If a fixture is pinned to the table, its offset is valid every time you mount it.

5. Probing

A 3D touch probe turns "find the edge of the part" into a button press, and is far more accurate than an edge finder or eyeballing. Probe Basic's probing suite is its biggest strength.

Setting up the probe

The probe is a tool

The probe gets a tool number, set as Probe Tool # on the TOUCH PROBE page (parameter #3014; 99 is common). Its tool-table entry needs:

  • Diameter: the ball diameter, measured with a micrometer. The reference machine's "2 mm" ball measured 1.998 mm.
  • Length: measured like any tool, but gently. Either use TOUCH OFF CURRENT TOOL on the tool setter at a slow feed, or touch the probe and a cutter on the same flat surface and compare.

Every probing routine first checks that the probe tool is the one in the spindle, and aborts with "Specified probe tool … not in spindle" if not. Always load it with M6 G43 so its length is applied (chapter 1 explains why).

Wiring note: normally open vs normally closed

A normally-open (NO) probe reads "not triggered" when it is unplugged or its cable is broken. Probe Basic will then drive it into the part until the stylus overtravel limit or a crash. Tap-test the probe before every probing session. A normally-closed (NC) probe fails safe, which is why industrial probes use NC.

Calibration (CALIBRATE page)

The ball triggers a little before its surface actually touches. That's the "pretravel", and it makes the ball's effective diameter slightly smaller than the real one. Calibration measures this once:

  1. Clamp a ring gauge (or any precisely known bore) to the table.
  2. Enter its diameter in CALIBRATION DIAMETER.
  3. Put the probe roughly in its center, below the top edge.
  4. Run the round-pocket calibration.
  5. Choose which error to store: CAL ON AVG XY ERROR, CAL ON X ERROR or CAL ON Y ERROR.

The result is the PROBE CALIBRATION OFFSET (#3032). It is subtracted from the ball radius in every edge calculation. PROBE CAL RESET clears it. There are also boss and square calibrations for when you have a gauge pin or a gauge block instead of a ring.

On the 6040. A 24.995 mm ring gauge gave different results in X and Y: the X width read 0.040 mm smaller than Y. That isn't the probe; it's axis backlash. The two axes have different amounts of lost motion, and a single calibration offset can only correct one of them. Measuring backlash with a dial indicator and entering BACKLASH in the INI fixes the root cause. Until then, calibrate on the axis you care about most.

PROBE POSITION ONLY and PROBE RESULTS

PROBE POSITION ONLY is the single most important switch on this page:

  • On: routines measure and fill in PROBE RESULTS (X−/X+/Y−/Y+/Z− probed positions, X and Y WIDTH, DIAM, X and Y CENTER, EDGE Δ, EDGE ∠). Your work offset is not touched. Use this for inspection, for example "is this bore 25.00 mm?".
  • Off: routines also write the result into the active work offset (G54 unless you selected another). Use this to set up a job.

Leave it on by default and switch it off only for the probing move that sets your zero. That habit prevents the classic surprise of a measurement silently moving your work offset.

RESET ALL DATA / X DATA RESET / Y DATA RESET clear the results panel.

The routines

Each routine page shows pictures of where to start and which way the probe will move. The common rules:

  • The probe must be in the spindle with G43 on.
  • Start above the part, within MAX Z DISTANCE of the top, unless the routine says to start below the edge.
  • For routines that step off an edge, start within STEP OFF WIDTH of that edge, measured inward. The probe moves out by the step-off width, drops, and touches back toward you. Start too far in, and it drops onto the top of the part.

OUTSIDE CORNERS

A 3×3 grid of buttons:

  • Four corners: each touches the top (Z), then the two edges that meet at that corner, and sets X, Y and Z zero on that corner. Start over the part near the chosen corner, within step-off width of both edges.
  • Four edges: top-left side, front, back, right side. Each finds one edge (and Z).
  • The center button: touches Z only.

INSIDE CORNERS

The same idea inside a pocket or against a fixture's inside corner, plus single-direction X+/X−/Y+/Y− touches and a Z touch. Start inside, below the top edge, within MAX X/Y DISTANCE of the walls.

BOSS AND POCKET

Six buttons in two rows:

Top row (round) Bottom row (rectangular)
Round pocket (start below the top edge) Rect pocket (start below the top edge)
Round boss (start above, centered) Rect boss (start above, centered)
Round pocket, center start (start above) Rect pocket, center start (start above)

They find the center, and for round features the diameter. Hints matter: for bosses and center-start pockets the probe steps out to half the hint (X/Y HINT, or DIAM for round) plus the step-off width before it drops. Enter sizes within a few millimetres.

RECT BOSS is the everyday "center of the stock" routine. See the diagram in chapter 3.

RIDGE AND VALLEY

Finds the center of a rib (ridge) or a slot (valley), in X or in Y, with its own X/Y hints. Use it for the center of a T-slot, a keyway or a narrow bar.

EDGE ANGLE

Touches one edge at two points, EDGE WIDTH apart, and reports the angle (EDGE ∠) and the offset between the touches (EDGE Δ). Use it to check that a vise or part is square to the axes. SET ROTATION WCO stores the angle as the work offset's rotation (the R column on the OFFSETS tab), so programs run rotated to match a part that is clamped crooked.

On the 6040. Two edge-angle readings on a glued-down 1-2-3 block, plus two RECT BOSS measurements in both orientations, showed the X axis measuring 0.323 % long. The ballscrew's lead was slightly under 5 mm. X SCALE was corrected from 320 to 321.034 steps/mm, and the block then measured right to 0.001 mm. A probe and a gauge block make a cheap machine calibration kit.

ROTARY AXIS

Probing routines for a 4th axis: centering on a cylinder in the rotary chuck.

PROBE HELP

Pages of built-in diagrams for every routine (PREV PAGE / NEXT PAGE). Worth reading once.

A good probing habit

  1. Load the probe with M6 G43, and tap-test it.
  2. Check hints and the starting position against the routine's picture.
  3. First run with PROBE POSITION ONLY on, and check the numbers make sense.
  4. Turn it off, run again to set the offset, then turn it back on.
  5. Sanity-check Z with a ruler before the first cut (chapter 3, step 5).

6. The tool setter, and measuring every tool automatically

A tool setter is a switch at a fixed spot on the table. Lowering a cutter onto it tells LinuxCNC exactly how far that cutter's tip sits below the spindle reference, which is its tool length. With one, tool changes stop being a source of depth errors.

One-time setup (PROBING → TOOL SETTER)

1. Wire it to the probe input

LinuxCNC has one probe input (motion.probe-input). If you have a 3D probe, a touch plate and a setter, OR them together in HAL so any of them triggers probing. On the reference machine the setter is normally-closed, so its input is inverted (input-06-not) before the OR. See config/6040_7i96s/hallib/6040_7i96s.hal.

2. Set the touch-off position (G30)

  1. Jog the spindle so its centerline is over the middle of the setter's button.
  2. Raise Z to the top (machine Z0).
  3. Press SET TOOL TOUCH OFF POS.

This stores the position as G30 (parameters #5181–#5183). GO TO G30 returns there.

3. Set SPINDLE ZERO (#3010)

SPINDLE ZERO is the distance from machine Z0 down to the setter's trigger point, measured with the reference surface: the bare collet nut, or whatever you call "length zero". Probe Basic's own help text says it must be entered as a positive number.

  • The direct way: with no tool in the spindle (nut only), jog down slowly until the setter triggers, and enter the distance travelled.
  • PROBE SPINDLE NOSE ZERO automates this if your spindle nose can safely press the setter.

On the 6040. SPINDLE ZERO was first worked out from a caliper measurement of a tool's stick-out. That turned out to be 0.565 mm off, because measuring stick-out by caliper is harder than it looks. Measuring with the bare nut (49.1901 mm) fixed it, and every stored tool length and the G54 Z were shifted together by the same amount. Lesson: calibrate the reference directly. Don't derive it from a measured tool.

Measuring a tool by hand

Load the tool (T box + M6 G43, or T5 M6 in MDI), then press TOUCH OFF CURRENT TOOL on the TOOL tab. The machine:

  1. lifts to machine Z0 and moves to the G30 position,
  2. probes down fast, retracts, probes slowly,
  3. lifts back to Z0,
  4. stores the length in the tool table, and applies G43 for that tool.

Repeatability on the reference machine: about 0.007 mm.

Measuring at every tool change (M6 remap)

By default, M6 in LinuxCNC only asks you to change the tool; it doesn't measure it. Unless you measured each tool beforehand, a program would then run with whatever length is in the table. Changing what M6 does is called a remap. This one makes every tool change, from a program, MDI or the M6 G43 button, measure the new tool.

The subroutine, subroutines/pb_m6_touchoff.ngc:

o<pb_m6_touchoff> sub
M5                          (spindle off before anything moves to the setter)
M6                          (built-in manual change: Z up, insert-tool prompt)
M66 E0 L0                   (stop read-ahead so the new tool is current)
o100 if [#<_task> EQ 1]
  o110 if [[#<selected_tool> GT 0] AND [#<selected_tool> NE #3014]]
    o<tool_touch_off> call
  o110 endif
o100 endif
o<pb_m6_touchoff> endsub [1]
M2

And in the INI:

[RS274NGC]
REMAP = M6 modalgroup=6 prolog=change_prolog ngc=pb_m6_touchoff epilog=change_epilog

[PYTHON]
PATH_PREPEND = python
TOPLEVEL = python/toplevel.py

The python/ folder holds LinuxCNC's standard remap glue (toplevel.py → remap.py → stdglue.py). Probe Basic's sample configs already include it.

Details that matter:

  • Inside a remap subroutine, M6 means the built-in tool change. It doesn't call itself.
  • #<_task> EQ 1 is true only when the program really runs. The preview interpreter has _task = 0. Without this guard, the preview tries to "probe", the probe never triggers, and the preview stops after a few lines.
  • The probe tool is skipped, so the setter never presses the probe's stylus. T0 (empty spindle) is skipped too.
  • endsub [1]: the standard epilog requires the remap to return a value.
  • Comments can't contain parentheses. (T99 (probe)) is an error in G-code. The interpreter stops with "nested comment".

After enabling it, a Fusion 360 program with plain T5 M6 lines measures every tool with no edits. See chapter 10.

7. The tool table

Where it lives

Probe Basic 1.0.x can keep the tool table in an SQLite database instead of LinuxCNC's classic tool.tbl text file. The INI selects it:

[EMCIO]
DB_PROGRAM = ./tool_db.sh
TOOL_DB_FILE = 6040_tools.db

tool_db.sh starts QtPyVCP's tool_db_backend, which answers LinuxCNC's tool queries from the database. The TOOL tab edits the same file. One database is the single source of truth: diameter, length, remark and the ATC flag.

Columns

Column Meaning
T Tool number: what T5 and H5 refer to.
P Pocket. Only matters for an ATC.
Z Tool length (from the setter).
D Diameter: used by cutter compensation and the preview, and by the probe routines for the ball.
ATC Whether the tool fits the automatic changer's carousel. Unused without an ATC.
Remark Free text: maker, flute count, stick-out, collet.

Edit cells, then SAVE TABLE. ADD TOOL and DELETE manage rows. UPDATE LOADED TOOL pushes edits for the tool in the spindle.

Numbering advice

  • Use the same numbers as your CAM library. If Fusion's library has your 1/8" O-flute as tool 12, make it T12 here too. Then posted programs need no renumbering.
  • Reserve a high number for the probe (99 is conventional), so a program can never call it by accident.
  • Put stick-out and collet in the remark, so the next time you load the tool you set the same length.

If LinuxCNC says "tool not found in tool table"

The database file is probably fine; LinuxCNC's in-memory copy is not. Reload it, or restart LinuxCNC. On the reference machine, a standalone rs274 dry run on the same PC overwrote it. See chapter 11.

8. Running programs

Starting

CYCLE START runs the loaded program. If it does nothing and the button doesn't highlight when you hover over it, the GUI considers the machine not ready. Check:

  • the machine is on and homed (REF ALL shows HOMED),
  • a program is loaded,
  • nothing else (MDI, a probing routine) is still running.

Toggling POWER off and on forces Probe Basic to re-check its state. That cleared a stuck CYCLE START on the reference machine after modes had been changed from outside the GUI.

Watching the first moves

  • F slider at 25–50 % for the first plunge of any new program. Every feed move is scaled; rapids are not.
  • SINGLE BLOCK to step line by line through the start.
  • Dry run in the air. Temporarily raise G54 Z (for example 20 mm higher) and run the start of the program above the part. Put it back afterwards.
  • Test in scrap. Run the program once in wood or plastic before the expensive stock, as the reference machine did with plywood before aluminum.

Pausing and resuming

You want to… Do this
Pause briefly (chips, check something) FEED HOLD, then CYCLE START. Your place is kept. The spindle keeps running.
Pause at a planned point Put M1 in the program and light M01 BREAK, or use M0 (always stops).
Stop the spindle mid-job FEED HOLD, then STOP. Note the line number, and later use RUN FROM LINE at the start of an operation.
Emergency E-stop. Everything stops; you will need to re-enable, and usually re-home.

RUN FROM LINE starts partway through, but it doesn't replay what came before: position, tool, tool length, work offset, spindle and coolant. Start at a line where the program sets all of them itself. In Fusion output, that's the comment line that begins an operation, right before its T… M6.

Overrides during the job

  • Feed: 100 % is what the CAM asked for. In soft materials it is usually safe to go above 100 % once you have heard the cut. In metal, raise it slowly and listen.
  • Spindle: adjusts rpm live. On a VFD controlled over Modbus the change is immediate.
  • Rapid: turn it down when a program has long rapids near clamps you are unsure of.

Dry cutting aluminum (no coolant)

Without coolant, the risk is chips being re-cut and welding to the flute, which snaps small cutters. On the reference machine:

  • Single-flute cutters (O-flute or 1F upcut): a deep flute, and the biggest possible chip per tooth.
  • Feed high enough to make real chips: about 0.05–0.1 mm per tooth programmed. Thin chips rub and heat the tool.
  • Adaptive (trochoidal) roughing: light radial engagement, full flute engagement in depth.
  • Air blast or vacuum at the cutter for the whole run. That matters more than any feed setting.

9. Conversational programming

The CONVERSATIONAL tab writes simple G-code from a form, with no CAM needed. Its pages:

Page Makes
FACING A zig-zag facing program over a rectangle. Good for surfacing a wasteboard or squaring stock.
HOLE OPS Drilling, peck drilling, tapping and boring cycles, at positions from XY COORD (a list of points) or PATTERN (bolt circles and grids). THREAD MILL generates helical thread milling.
PERIMETER A profile around a rectangle or circle.
POCKETS Rectangular and circular pockets.
MISC Smaller utilities.

The general flow:

  1. Fill in the tool (number, diameter), spindle speed, feeds, depths and stepovers.
  2. Fill in the geometry.
  3. Post the program to a file, or send it straight to the loaded program.
  4. Check it in the preview like any other program, then set the work offset and run.

On the 6040. The first real use of the machine after the LinuxCNC conversion was a FACING program to surface the wasteboard: a 1" (25.4 mm) 3-flute surfacing bit over the full usable table. The start and end values are in work coordinates, so set the work offset before filling in the form, and check the preview (PGM EXT) before running. A wrong sign or an end value outside the travel shows up immediately as a facing area hanging off the table.

10. From CAM to Probe Basic (Fusion 360)

Any CAM that posts LinuxCNC G-code works. This chapter uses Fusion 360, as on the reference machine.

The post processor

Use Fusion's stock LinuxCNC post (linuxcnc.cps). It writes .ngc files with G54, T# M6, G43 H#, S… M3 and the arcs LinuxCNC expects. Mach3 posts mostly work too, but they add Mach-isms and sometimes .tap extensions. The LinuxCNC post is cleaner.

Settings that matter

"Manual tool change" in the tool library

Fusion tools have a Manual tool change checkbox. When it is ticked, the LinuxCNC post writes:

M0
(MANUAL TOOL CHANGE TO T12)

That's a plain stop, not T12 M6. LinuxCNC then never learns which tool is loaded, an M6 remap never runs, and G43 H12 uses whatever length is in the table. Untick it for every tool, so the post writes T12 M6. That gives a real tool change, measured by the M6 remap (chapter 6).

Tool numbers

Make Fusion's tool numbers match the Probe Basic tool table (chapter 7). The post's T12 M6 and G43 H12 then just work.

Work coordinate system and origin

In the Fusion setup, set WCS offset = 1 (G54). Put the origin where you will probe it: for example the top center of the stock, matching a RECT BOSS on the stock. The stock top is Z0 if you probe the top; if you will face the stock, add the facing allowance in the setup's stock offsets.

Coolant

If the machine has no coolant outputs, set coolant to Disabled in the operations, so no M7/M8 is posted.

Two Fusion gotchas found the hard way

  1. 2D Contour on pocket floors cuts on the wrong side. A face-contour selection defaults to side type "Start outside". On pocket floor faces, that put the tool outside every pocket outline, through all the ribs. In the API, set sideType = AlwaysInsideSideType. In the UI, check the red arrow on every contour, and check the simulation.
  2. Contours on a face with holes trace the holes too. An outside profile selected from the part's bottom face also tried to cut around each through-hole. Restrict it to the outer loop (loopType = OnlyOutsideLoops).

Both were caught by checking the posted G-code against the model before cutting: a small script steps through every move and measures the cutter's clearance to the part. Simulate in Fusion at the very least.

Checking a program before it runs

  • Preview in Probe Basic: the whole path should draw, and PGM EXT should frame what you expect.
  • Deepest Z: search the file for the most negative Z. It should be the deepest feature, or a through cut slightly into the spoilboard or tape, never more.
  • Tool calls: every T# M6 should be followed by G43 H# with the same number.
  • First moves: run with the feed override low, or in the air.

11. Troubleshooting (every one of these happened)

Z zero is off by exactly the probe's length

Cause: The probe was in the spindle, but G43 wasn't active when you probed. LinuxCNC measured with the collet nut as the reference, so Z0 ended up one probe-length (46.87 mm here) too high. Fix: Load the probe with T 99 → M6 G43, and check that the G43 button is lit and LENGTH shows the probe length. Re-probe, or correct G54 Z by subtracting the probe length. Check: With the probe loaded and G43 on, the DRO Z equals the ball's real height above the part.

"Requested tool 18 not found in tool table" (but it is in the table)

Cause: something overwrote LinuxCNC's in-memory tool table. On the reference machine it was the standalone interpreter, rs274, run on the same PC while LinuxCNC was up to dry-test G-code. It shares the live machine's tool-table memory and replaced it with its own. That happened twice: once with an empty table, once with a 3-tool test table, during a running job. Fix: In MDI or a Python shell, reload the table from the database (linuxcnc.command().load_tool_table()), or restart LinuxCNC. The database file itself is unaffected. Prevent: never run rs274 (or a second LinuxCNC) on the machine's PC while LinuxCNC is running. Dry-test G-code on another computer, or with LinuxCNC closed. Also check: exactly one io process and one tool_db_backend (pgrep -a -f "io -ini"). A leftover io from a crashed session should be killed with LinuxCNC closed.

The preview shows only a few lines of the program

Cause: The program calls a subroutine that probes (a tool touch-off, for example). The preview interpreter can't probe, the routine aborts with "probe failed", and the preview stops there. Fix: Wrap such calls in o100 if [#<_task> EQ 1] … o100 endif. _task is 1 only in the real run.

CYCLE START does nothing and doesn't highlight

Cause: The GUI thinks the machine isn't ready. It happened after modes were switched from outside the GUI, by a script over SSH. Fix: Toggle POWER off and on. Check homed status and that a program is loaded. Look at the STATUS tab.

"Motion enabled after reaching a coordinate soft limit with active external offsets"

Cause: An informational note. The machine was switched on while an axis sat exactly on a soft limit (Z at machine 0 after a tool change), and the config has external offsets enabled even though they aren't used. Fix: Nothing. It is harmless.

"Probe move would exceed Z negative limit" on a second touch-off

Cause: LinuxCNC rejects a G38 probe move if its full search length would pass the soft limit, even if the probe would trigger sooner. Fix: Clamp the search distance to the room left above the limit (see touch_plate.ngc).

"G38.2 move finished without making contact" (but it touched)

Cause: The touch plate or probe was moved, or lifted, between the fast and slow touches. The second, slow touch then found nothing. Fix: Leave the plate in place until the routine finishes and lifts.

Probing writes your work offset when you only wanted to measure

Cause: PROBE POSITION ONLY was off. Fix: Leave it on by default. Turn it off only for the run that sets the zero.

X and Y calibrate differently on a ring gauge

Cause: Different backlash per axis. A single probe calibration offset can't correct both. Fix: Measure backlash with a dial indicator, set BACKLASH per joint in the INI, then recalibrate.

Parts come out the wrong size by a fixed percentage on one axis

Cause: Steps per mm (SCALE) don't match the real ballscrew lead. Fix: Probe a gauge block or 1-2-3 block in two lengths along that axis, and correct SCALE by the ratio. Using the difference of two lengths cancels the probe and backlash terms. On the reference machine: X 320 → 321.034.

The VFD shows Err16 when LinuxCNC is closed

Cause: Normal on a Modbus spindle. The VFD's comms-timeout protection trips when nothing polls it. Fix: None needed. The Modbus init list sends a fault reset when LinuxCNC starts.

A G-code comment with parentheses breaks a subroutine

Cause: G-code comments can't nest. (T99 (the probe)) is an error. Fix: Use (T99 = the probe).

How the conversion went, in brief

  2. Card on the bench: readhmid, a 30-minute link test with 0 errors.

  4. Rewired the stepper drivers common-anode at 5 V; homing, limits and travel set.
  5. Flashed PktUART firmware, wired RS-485 to the VFD (with the pair swapped), and set the VFD to standard Modbus (Pd-05 = 31). The spindle ran under LinuxCNC control.
  6. Added the E-stop, tool setter, 3D probe and pendant; calibrated the setter, probe and X scale.
  7. First job: a facing program for the wasteboard, then an isogrid plate (plywood test, then aluminum) from Fusion 360.
